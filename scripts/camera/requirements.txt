# Python dependencies for analyze_frames.py
#
# Install into the SAME interpreter that runs the script. `analyze_frames.py`
# starts with `#!/usr/bin/env python3`, so that is whichever python3 comes
# first on your PATH - check with `which python3` before installing, and
# install with `python3 -m pip` rather than a bare `pip`, which may well
# belong to a different python.
#
#     python3 -m pip install -r requirements.txt
#
# Or, to keep these out of a system or conda python, as when running on a Mac:
#
#     python3 -m venv .venv
#     source .venv/bin/activate
#     pip install -r requirements.txt
